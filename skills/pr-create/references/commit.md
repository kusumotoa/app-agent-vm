# コミットメッセージ

`git log` を見て、リポジトリに既存の書き方があればそれに合わせる。
無ければ次の形で書く。

```text
<type>: <説明>
```

| type | 用途 |
|---|---|
| `feat` | 新機能 |
| `fix` | バグ修正 |
| `refactor` | リファクタリング |
| `perf` | パフォーマンス改善 |
| `test` | テスト |
| `docs` | ドキュメント |
| `style` | フォーマット |
| `chore` | その他 |
| `ci` | CI 設定 |
| `ui` | UI/UX |

破壊的変更は `feat!:` のように `!` を付ける。
