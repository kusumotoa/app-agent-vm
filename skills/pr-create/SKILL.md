# Pull request

判断に要るものはすべて pull request のページに載せる。

```bash
git add -A && git commit -m "..."
git push -u origin @
```

**作業ブランチを自分で切る。** デフォルトブランチへ直接 push しない。

コンフリクトしていないかは `gh pr view --json mergeable` で見る。していたらデフォルトブランチを
自分のブランチに merge して直す。履歴は書き換えない。

Draft で出す。マージはしない。Draft も外さない（`gh pr ready` は使わない）。どちらも人がする。

## 出す前に動かす

**変更前と変更後を、同じ操作で撮って並べる。** 挙動が変わらない修正も撮り、変わらないことを見せる。
画面に出るものは画像と動画、出ないものは出力。撮り方は[画像と動画](references/media.md)。
docs だけなど動かすものが無いときは省き、本文に理由を書く。

変更前は、デフォルトブランチを別のディレクトリに出して撮る。自分のブランチは動かさない。

普通の操作のほかに、崩れやすいところを見る。

- 空、エラー、読み込み中
- 長い文字列、文字サイズの拡大
- ダークモード
- 通信が遅い、切れている
- 権限を拒否したとき

この環境で確かめられないことは本文に書く。実機、課金、プッシュ通知。
