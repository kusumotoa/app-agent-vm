# レビュー

**PR の本文と差分。** 本文は `gh pr view --json body` で取る。書いてあるのにやっていないこと、
やっているのに書いていないことを挙げる。「置き換えた」「消した」と書いてあるなら、
削除行があるか確かめる。

**テストが振る舞いを見ているか。** 定数が自分自身と等しいことや、文字列の組み立てだけを
確かめるテストは、あっても何も守らない。差分で足した関数が呼ばれているかを見る。

**使われていない拡張点。** 注入できる作りにしてどこからも注入していない引数、
呼ばれていない分岐。要らないなら消す。

**動かして確かめる。** 見た目が変わる差分は、PR の画像を信じず自分で動かす。
画面は、ツールが返す UI の階層（文字）で確かめる。画像は開かない。
色や余白の崩れは確かめられないので、人に任せると書く。
文字で分かった違いは、画像や動画を付けてコメントに書く。
